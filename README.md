# Field Notes

A simple mobile application for taking, saving, and managing field notes anywhere, anytime.

## Features
- Add a new field note with title, category, location, and content
- View all saved notes in a list
- Search notes by title or content
- Delete notes you no longer need
- Auto-save using local storage - notes stay even after refresh

## How to Install and Run
1. Open this link: https://hylndml00-21.github.io/field-notes-app/
2. Or download/clone this repository and open `index.html` in any browser
3. No installation needed. Works on mobile and desktop.
